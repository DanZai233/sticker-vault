# 开发与验证

## 测试边界

Node 测试使用隔离临时目录与构造图片，不需要个人账号：

- SQLCipher 分页 HMAC 校验 / 篡改拒绝及 AES 动图还原不重编码。
- 多帧 GIF 识别、原始字节保真、内容去重、并发导入和元数据重载。
- QQ 只读取 personal_emoji/Ori，错误 JPG 扩展名中的 GIF 依然是动画，跳过缩略图，增量指纹保存后不会重复添加已移除条目。
- 抖音只接受自定义收藏列表，动画地址优先，缺失动画地址不退回静态图，图片 CDN 域名与重定向限制。

真实账号、原生目录授权、辅助功能授权和聊天软件的粘贴 / 拖拽需要手动验证，CI 不拥有这些数据与权限。不能把构建安装包成功写成所有平台实机验收通过。

## 建议手动检查

1. 隔离素材库中导入 GIF、APNG、动态 WebP、PNG 与错误扩展名的图片，确认动画、导出字节及去重。
2. 关联目录新增文件，等待扫描；模拟拒绝权限、源目录消失和下载失败，确保现有素材仍可使用。
3. 拖到 Finder / Explorer 临时目录，核对 SHA-256；再按聊天软件分别检查，不自动向别人发送测试消息。
4. 复制原文件后粘贴到文件管理器 / 聊天输入框，确认动图仍是原文件。
5. 点击托盘与快捷键，搜索并选择表情；macOS 分别在未授权与已授权辅助功能时验证手动 / 自动粘贴，确认不发送回车。
6. 最近使用更新、重启后排序、关闭主窗保留托盘、右键退出。
7. 微信首次副本登录、已缓存密钥、原微信仍运行、登录超时与取消等场景；抖音登录后打开 / 滚动收藏面板、关闭再打开及失败恢复。

## 机密与日志

不要提交真实表情、账号标识、数据库、Cookie、密钥或原始网络响应。`.gitignore` 只是辅助，推送前还需检查 `git diff --cached`。助手错误日志仅用于本机排查，分享前检查路径和账号信息。

## 原生助手

`macos-insert.swift` 使用 NSPasteboard 的文件 URL 保存整个原件，不写单帧位图。捕获面板打开前的前台应用，辅助功能已授权时恢复该应用并模拟 Command+V；未授权时只复制并给出说明。不模拟 Return，不触发自动发送。

编译命令见 scripts/build-native.cjs。macOS x64 和 arm64 要各自编译；CI 将原生助手放到安装包资源目录外层，不能从 ASAR 内 spawn 可执行文件。
